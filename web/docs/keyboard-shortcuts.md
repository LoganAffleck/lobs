These are the built-in shortcuts. Global hotkeys, the ones that work while a game has focus, have no defaults. You set them in [Settings > Hotkeys](/docs/settings/#hotkeys).

## Anywhere in the window

| Keys | Action |
|---|---|
| Ctrl+, | Open Settings |
| Ctrl+Z | Undo |
| Ctrl+Shift+Z or Ctrl+Y | Redo |
| Ctrl+D | Duplicate the selected layer |
| Ctrl+G | Group the selected layers |
| Ctrl+Shift+G | Ungroup |
| Ctrl+] | Bring forward |
| Ctrl+[ | Send backward |
| Ctrl+Shift+] | Bring to front |
| Ctrl+Shift+[ | Send to back |
| Delete | Delete the selected layer |
| Ctrl+S | Save (asks where) |
| Ctrl+O | Open a show |

## Canvas

These work while the canvas has focus.

| Keys | Action |
|---|---|
| V | Select tool |
| T | Text tool |
| R | Rectangle tool |
| O | Ellipse tool |
| A | Arrow tool |
| P | Pencil tool |
| L | Laser pointer |
| Arrow keys | Nudge 1 px |
| Shift+arrow keys | Nudge 10 px |
| Delete or Backspace | Delete the selected layer |
| Esc | End crop mode, or go back to the Select tool |
| Enter | End crop mode |

The window-wide shortcuts for undo, duplicate, group and order also work here.

### Mouse modifiers

| Modifier | Effect |
|---|---|
| Shift | Resize freely (without keeping proportions); draw a square, a circle or a 45-degree arrow; Shift+click adds to the selection |
| Ctrl | Move without snapping |
| Alt | Move, resize, crop or draw while [live lock](/docs/going-live/#live-lock) is on |

## Typing text on the canvas

| Keys | Action |
|---|---|
| Enter | New line |
| Backspace | Delete the last character |
| Esc or Ctrl+Enter | Finish |
| Any other Ctrl or Alt shortcut | Finish, then run the shortcut |

## Number fields

| Keys | Action |
|---|---|
| Up / Down | Change by 1 |
| Shift+Up / Shift+Down | Change by 10 |
| Drag sideways | Scrub |
| Shift while scrubbing | 10 times faster |
| Ctrl while scrubbing | 10 times slower |

## Assets panel

These work while the Assets panel has focus.

| Keys | Action |
|---|---|
| Ctrl+C | Copy |
| Ctrl+X | Cut |
| Ctrl+V | Paste |
| Ctrl+A | Select all |
| Ctrl+N | New folder |
| Ctrl+F | Search all folders |
| Delete | Move to Recycle Bin |
| F2 | Rename |
| Backspace | Up one folder |
| Enter | Place on the edited scene |

## Other places

| Where | Keys | Action |
|---|---|---|
| Settings | Esc | Close Settings |
| Hotkey field | Backspace or Delete | Clear the hotkey |
| Hotkey field | Esc | Cancel |
| Color picker | Esc | Cancel **Pick from screen** |
| Projector | Esc | Close the projector |
| Projector | Double-click | Leave full screen |
| Twitch panels | Ctrl+plus / Ctrl+minus | Zoom in or out |
